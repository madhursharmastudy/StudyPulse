# Stretch Break Exercise Media Assets

Place short looping silent MP4 video clips or animated WebP files in this folder for the body stretch suggestions.
If any file is missing, the app automatically shows an animated pulsing posture illustration with zone indicators.

## Media Files Expected:

### Fixed Exercises (Every full break):
1. `chin_tuck.mp4` - Chin tuck (Zone: NECK)
2. `wrist_stretch.mp4` - Wrist stretch (Zone: SHOULDER_HAND)
3. `standing_back_extension.mp4` - Standing back extension (Zone: BACK)
4. `calf_raises.mp4` - Calf raises (Zone: LEGS)

### Seated Alternative Exercises (When 'Only sitting exercises' is enabled):
5. `seated_posture_hold.mp4` - Seated posture hold (Zone: BACK)
6. `ankle_pumps.mp4` - Ankle pumps (Zone: LEGS)

### Shuffled Pool Exercises (Rotated 2 per break):
7. `neck_side_stretch.mp4` - Neck side stretch (Zone: NECK)
8. `upper_trap_stretch.mp4` - Upper trap stretch (Zone: NECK)
9. `isometric_neck_press.mp4` - Isometric neck press (Zone: NECK)
10. `shoulder_rolls.mp4` - Shoulder rolls (Zone: SHOULDER_HAND)
11. `overhead_reach.mp4` - Overhead reach (Zone: SHOULDER_HAND)
12. `seated_twist.mp4` - Seated twist (Zone: BACK)
13. `seated_hamstring_stretch.mp4` - Seated hamstring stretch (Zone: LEGS)
14. `ankle_rotations.mp4` - Ankle rotations (Zone: LEGS)
